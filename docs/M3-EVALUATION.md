# M3 — Detector v1 evaluation against planted ground truth

> **Read this first.** Every number below comes from a **synthetic Poisson benchmark** generated by our own
> code. It validates that the detector is **implemented correctly and calibrated as designed** on data whose
> generating process is known. It is **not** an estimate of real-world epidemiological performance, which would
> require real surveillance data with verified outcomes.

* Detector: `windowed-gamma-poisson/1.0.0` (`windowed_gamma_poisson_v1`), config hash
  `23188f021f80bd84113165469456f72165be682522243f908cbb715793d104ba`, frozen and committed (`f5edec9`) before
  the held-out run; the harness refuses to run the held-out split if the code's config hash differs.
* Operating threshold: `alpha = 1e-4` for detection and for both survival checks — the **frozen
  high-specificity operating threshold for this version**, not a claim of epidemiological optimality.
* Matching rules: `match/1.0.0` (`src/evaluation/match.ts`). Artefact: `data/detection/m3-evaluation-v1.json`
  (results-summary SHA-256 `13c5e6d401c6fac975e0f562a83b1f3abaacb706f7679e7270a780fe9c82619a`); also stored in
  `evaluation_runs` (admin-only). Intervals: exact Clopper–Pearson for proportions; percentile bootstrap
  (2,000 resamples over datasets) for per-run rates.

## Protocol

| Split | Seeds | Content | Use |
|---|---|---|---|
| dev null | 1–50 | no planted events | calibration sanity (free to inspect) |
| dev replicates | 101–150 | 4 random clusters + 2 random decoys each | design diagnostics (free to inspect) |
| **held-out replicates** | **1001–1200** | 200 datasets, 800 clusters, 400 decoys | reported results; inspected once, after the freeze |
| **held-out null** | **2001–2200** | 200 datasets, no planted events | false-alarm calibration |
| canonical M2 dataset | 20261007 | P1–P4 + decoy D1 | illustrative (seen during planning, not held out) |

Replicate clusters: random syndrome, district, 1 block (60%) or 2 blocks of one district (40%), onset day
24–70, duration 5–12 days, rate multiplier 4–15, plateau (70%) or ramp. Decoys: one bulk import (1 day × 40 or
3 days × 25 `imported_dataset` reports) and one clinic batch (1 day × 30 or 3 days × 20 `clinician` reports),
severity unknown, placed >= 16 days from same-syndrome/same-block clusters.

**Definitions.** *Episode* = merged run of the detector's alarms. *Detected cluster (TP event)*: an episode with
the same syndrome and an overlapping block, whose first **credited** alarm is on or after day 2 of the event,
has alarm windows covering >= min(2, duration) event days, and occurs no later than 2 days after the event ends.
*Missed cluster (FN)*: otherwise. *TP episode*: credits a true cluster (extra crediting episodes are
*fragments*, not FPs). *FP episode*: credits no true cluster ("decoy" FP if it overlaps a decoy, else
"spurious"). *TN / FPR*: unit = block × syndrome × day; positives = cluster blocks/days; a grace zone (event end
→ +14 days) is excluded; FP unit = alarmed negative unit. *Evaluable cluster*: realised reports in the window
>= 5 on >= 2 days. Ground truth is read only by the evaluator; a test enforces that the detector cannot import it.

| Metric | Result (95% CI) |
|---|---|
| **Cluster recall**, all | **505/800 = 63.1%** (59.7–66.5%) |
| Cluster recall, evaluable clusters | 505/706 = 71.5% (68.0–74.8%) |
| Recall, non-sparse syndromes (diarrhoeal, fever, respiratory) | 446/480 = 92.9% (90.2–95.0%) |
| **Precision** (episodes) | **504/594 = 84.9%** (81.7–87.6%) |
| **False episodes per 90-day run**, replicates | **0.45** (0.385–0.52); 0 spurious, all 90 overlap a decoy |
| **False episodes per 90-day run, null datasets** | **0.01** (0–0.025); 2 of 200 runs had any |
| **False-positive rate** (unit-days), null | 0.06 per 10,000 (0–0.16); specificity 0.999994 |
| False-positive rate (unit-days), replicates | 14.2 per 10,000 (12.3–16.1); driven by clinic-batch decoys; specificity 0.99859 |
| **Detection delay** (detected clusters) | median **2 days** (IQR 2–4), mean 3.1; median 33% of the event's duration |
| Detected only after the event (late) | 1 of 800 |
| **Localization** | mean Jaccard 0.95; exact block set 89.9%; mean over-reach 0.11 blocks; correct district 99.8% |
| Fragmentation | 0.024 extra episodes per detected cluster |

### Decoys

| Variant | Rejected | Notes |
|---|---|---|
| bulk import, 1 day | 87/89 = 97.8% (92.1–99.7%) | every one examined and gated (bulk + burst) |
| bulk import, 3 days | 110/111 = 99.1% (95.1–100%) | gated by bulk; persistence alone would not stop it |
| clinic batch, 1 day | 104/104 = 100% (96.5–100%) | gated by burst/persistence |
| **Easy decoys combined** | **301/304 = 99.0%** (97.1–99.8%) | |
| **clinic batch, 3 days** | **6/96 = 6.3%** (2.3–13.1%) | **known limitation**: 90/96 alerted |

The 3-day single-source clinic batch (20 `clinician` reports/day) is, by counts alone, indistinguishable from a
genuine 3-day surge reported by one clinic, so the detector raises it as a candidate. Its single source type
lowers the score's source-diversity component, but no gate removes it. Human verification is the control.
Every decoy in every replicate was *examined* (a gated finding was logged), so rejections are not accidental
omissions.

### Sparse signals (P3-type)

| Syndrome | Recall |
|---|---|
| jaundice (baseline ~0.1 reports/block-day) | 25/163 = 15.3% (10.2–21.8%) |
| fever with rash (~0.2/block-day) | 34/157 = 21.7% (15.5–28.9%) |
| acute diarrhoeal / fever / respiratory | 146/162, 156/161, 144/157 |

By peak multiplier: < 6: 66/142; 6–10: 180/300; >= 10: 259/358. Sparse clusters are usually missed under the
evidence floor (= privacy threshold k = 5) and the high-specificity threshold. This is the trade-off chosen
for this version, not a defect to tune away.

### Priority bands (score is a ranking, not a probability)

high (>= 65): 451 episodes, 451 TP (100%, 99.2–100%) · medium: 132 episodes, 51 TP (38.6%, 30.3–47.5%) ·
low: 11 episodes, 2 TP. All decoy-driven false episodes landed in medium/low.

## Canonical M2 dataset (illustrative; n = 4, not held out)

| Event | Result |
|---|---|
| P1 diarrhoeal surge, Balianta | detected, delay 2 days, exact block |
| P2 fever-with-rash, Aska + Bhanjanagar | detected, delay 6 days, exact block pair |
| **P3 sparse jaundice, Nimapara** | **missed**: 9 realised reports over 11 days, never enough above the evidence floor at `p <= 1e-4` |
| P4 ramping diarrhoeal, Athagarh + Baramba | detected, delay 2 days, exact block pair |
| D1 one-day bulk import, Digapahandi | **rejected**; examined and gated by bulk, burst, persistence and ratio |

Recall 3/4 (19.4–99.4%), precision 3/4. The one false episode is respiratory illness in Brahmagiri: an
unplanted chance excursion in the synthetic background (visible during planning), correctly labelled false
positive by the oracle. With n = 4 the intervals are uninformative; the held-out replicates carry the evidence.

## Ablations and comparators (held-out replicates; null false episodes/run in brackets)

| Variant | Recall | False ep./run | Easy+hard decoys rejected | Null |
|---|---|---|---|---|
| **v1 (frozen)** | 63.1% | 0.45 | 307/400 | 0.01 |
| no gates | 71.9% | 2.11 | 24/400 | 0.315 |
| no bulk gate | 63.1% | 0.96 | 205/400 | 0.015 |
| no burst/persistence gates | 70.5% | 1.11 | 208/400 | 0.22 |
| plug-in Poisson test | 63.1% | 0.445 | 308/400 | 0.01 |
| fixed threshold (>= 5/day) | 56.6% | 19.1 | 0/400 | 16.8 |
| EARS-C2 (z > 3) | 53.9% | 30.1 | 0/400 | 27.9 |

Reading: the gates buy specificity at a measured cost in recall; with survival checks at `1e-4` the plug-in vs
predictive choice made almost no difference on this benchmark (the predictive test mattered before the survival
checks existed); both naive comparators produce tens of false episodes per run.

## Dev-split history (before the freeze)

Dev diagnostics led to two pre-freeze changes, both disclosed: the evaluation's decoy-alert definition no longer
double-counts episodes explained by a nearby true cluster; and the survival checks moved from `p <= 0.05` to
`p <= 1e-4` (dev: null false episodes/run 0.30 → 0; recall 75% → 61.5%). No change was made after the
held-out run started.

## Limits of this evidence

* Synthetic data drawn from a Poisson process close to the detector's model: correctness and calibration, not field performance.
* No reporting delays, no real seasonality beyond a single synthetic swing, no population denominators or adjacency.
* Decoy realism is limited to four constructed variants; real artifacts will differ.
* Recall depends strongly on syndrome baseline and effect size; real clusters may be smaller than these.
